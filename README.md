# 🌱 SarunenaLK

> Smart Agriculture Platform for Modern Farmers

---

## 📖 About

SarunenaLK is a modern Smart Agriculture Platform developed to assist farmers using digital technologies and Artificial Intelligence.

The platform provides intelligent farming recommendations, weather forecasting, AI assistance, crop management, market information, and educational resources to improve agricultural productivity and sustainability.

Our vision is to make agriculture smarter, more efficient, and more profitable for every farmer.
